# SpecLens

Open-source, local-first PRD intelligence and visualization engine.

SpecLens takes an existing Product Requirements Document and transforms it into structured product information that can be used to analyze requirements, generate user flows, identify edge cases, and eventually create functional MVP prototypes.

## Current Status

Early development.

### Current pipeline

PRD → Ollama → Qwen3 → Structured Product Analysis

## Planned Features

- PRD parsing
- Requirement extraction
- User story extraction
- Acceptance criteria analysis
- PRD quality analysis
- User flow visualization
- Edge-case visualization
- MVP prototype generation
- Local open-weight model support

## Local Development

SpecLens currently uses Ollama for local LLM inference.

Development model:

- Qwen3 4B
