# Task Creation

## Problem

Users need a simple way to keep track of work they need to complete.

## User Story

As a user, I want to create a task so that I can keep track of my work.

## Requirements

Users can create a task from the dashboard.

A task must have a title.

Users can optionally add a description.

Users can click the Create button to save the task.

After successful creation, the user should return to the dashboard and see the new task.

## Acceptance Criteria

- The title cannot be empty.
- A task should be created when valid information is submitted.
- The newly created task should appear on the dashboard.
